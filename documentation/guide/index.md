# Rusty Ruby 指南文档

## 概述

本目录包含 Rusty Ruby 项目的指南文档，提供了开发、维护、性能优化和测试的详细指导。

## 文档列表

| 文档名称 | 描述 | 路径 |
|---------|------|------|
| 开发和维护指南 | 开发流程、代码风格和维护指南 | [maintenance.md](maintenance.md) |
| 解释器改良指南 | 如何定位性能问题、改良解释器 | [interpreter.md](interpreter.md) |
| 验证和回归测试指南 | 如何验证修改和做回归测试 | [regression.md](regression.md) |

## 指南文档的作用

指南文档为开发人员提供了以下价值：

- **快速上手**：帮助新开发人员快速了解项目的开发流程和最佳实践
- **性能优化**：提供性能分析和优化的方法和技巧
- **故障排查**：指导开发人员定位和解决性能问题
- **质量保证**：确保代码质量和项目的稳定性

## 如何使用这些指南

1. **开发前**：阅读开发和维护指南，了解项目的开发流程和代码风格
2. **遇到性能问题**：参考解释器改良指南，定位和解决性能问题
3. **修改代码后**：使用验证和回归测试指南，确保修改的正确性
4. **定期参考**：定期查阅指南文档，保持对最佳实践的了解
