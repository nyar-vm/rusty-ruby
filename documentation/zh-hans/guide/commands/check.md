# 语法与语义检查 (Check)

`rbq check` 命令用于验证 `.rbq` 文件的正确性，包括语法解析和语义分析。

## 常用命令

### 检查指定文件或目录
```bash
rbq check ./models
```

## 检查内容

1.  **语法检查**：确保符合 RBQ 语言规范（如 `;` 结尾、类型定义正确等）。
2.  **语义检查**：
    - 类型引用是否存在。
    - 循环引用检测。
    - 注解参数合法性校验。
    - 命名空间冲突检查。

## CI/CD 集成

建议在代码提交钩子（Git Hooks）或 CI 流水线中运行 `rbq check`，以确保进入代码库的模型定义始终是合法的。

## 配置文件选项

`rbq.toml` 配置文件中与检查相关的选项：

### [project] 部分
- `source_dir`: RBQ 源文件目录，包含所有 `.rbq` 文件，默认为 "models"

### [databases] 部分
- `url`: 数据库连接字符串，格式根据数据库类型而定
- `schema`: 可选的数据库架构名称，如 PostgreSQL 的 "public"
